## 📌 Descrição

Esse projeto implementa um sistema de pagamentos via PIX, desenvolvido como trabalho para a disciplina de Sistemas Distribuídos.  
O objetivo é simular/implementar componentes distribuídos que permitem uso de transações PIX, tratamento de concorrência, consistência e comunicação entre nós.
